# Contributing

Thanks for helping improve **AICoder**.

## Before changing code

1. Work from the current default branch `master`.
2. Preserve unrelated local changes; do not reset or rewrite another contributor's work.
3. Back up files before destructive or broad edits.
4. Keep one logical change per commit.
5. Add or update regression tests when behavior changes.

## Verification

Run the repository-specific checks documented in `README.md`. A change is not complete until the relevant tests/lint/build checks pass or an external blocker is documented.

## Pull requests

Describe the problem, root cause, implementation, tests, compatibility impact, and any migration/security considerations. Do not include secrets or private production data.

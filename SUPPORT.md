# Support

- Project issues: use this repository's GitHub Issues for reproducible bugs and feature requests.
- Security vulnerabilities: **support@ailinux.me** (private disclosure; see `SECURITY.md`).
- Commercial / redistribution / OEM licensing: **support@ailinux.me**.
- AILinux website: https://ailinux.me
- Public MCP / Helper entry point: https://api.ailinux.me/v1/mcp

When asking for technical support, include the application version, OS/platform, exact error, reproduction steps, and sanitized logs.
